{{/* Country flags. Local SVG files under /static/img/flags, one per ISO 3166-1 alpha-2 code, in the project's own repository. Nothing is fetched from a CDN and nothing is hotlinked. Emoji flags are not used: they render inconsistently across platforms and not at all on many Linux and Windows configurations. These replace the handful of hand-drawn inline SVGs that used to live here — nine countries had a flag and the other one hundred and eighty-seven fell through to a grey rectangle. Sizing, the corner radius and the absence of any frame come from `.flag` in components.css, so every flag in the interface matches: the market selector, the language menu, map cards, the locate control and the drawer pills. The code is checked against the generated manifest before an is emitted. A code with no file behind it draws a neutral placeholder instead, because a broken-image icon is worse than a plain one. Always decorative: the country name or code is adjacent in text, so alt is empty and the image is hidden from assistive technology. Usage: {{ template "flag" "EE" }} */}} {{ define "flag" }} {{- $src := flagPath . -}} {{- if $src -}} {{- else -}} {{/* Unknown or missing code — a plain tile, never a broken image. */}} {{- end -}} {{ end }}
